# Domain documentation

This repository uses a single-context layout. Before engineering work, read
root `CONTEXT.md` when present and any applicable decisions under `docs/adr/`.
Their absence is not an error; proceed with the repository's existing terms.

Use domain terms exactly as defined in `CONTEXT.md`. If a proposed change
conflicts with an ADR, report the conflict explicitly rather than silently
overriding it. `grill-with-docs` may create these sources when decisions need
to be formalized.
